# Roadmap

## Near term

- Expand parser coverage for directives, comments, and richer term forms; add source-versus-compiled behavior tests.
- Replace adapter status/helper scaffolding with live transformations for representative inputs.
- Improve static analyses and provenance depth.
- Enforce backend memory budgets and implement actual dense, sparse, and stabilizer simulation semantics.

## Mid term

- Add measurement distributions and stronger quantum simulation fidelity.
- Implement executable hybrid partitioning and stronger equivalence/fallback verification.
- Extend benchmark depth and showcase workloads with realistic optimisation traces.

## Long term

- Tighten formal verification around transformation classes.
- Improve compression quality and hybrid planning heuristics using reproducible benchmark evidence.

See [Feature guide and implementation status](docs/FEATURES.md) for current scope and detailed limitations.
